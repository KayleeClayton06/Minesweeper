# Mine Sweaper

## Repository
https://github.com/KayleeClayton06/Minesweeper.git

## Description
I will create a program the user will interact with a screen to play minesweeper.

## Features
- Feature 1
	- The program will create a surface that is a board filled with tiles.
- Feature 2
	- Program will places mines randomly on the board.
- Feature 3 
	- Program will place numbers on tiles indicating how close they are to the mine.
- Feature 4
	- Player can interact with game and "dig" one tile at a time.
- Feature 5
	- If the player interacts with a mine it explodes.
- Feature 6
	- A win screen appears when the player wins.

## Challenges
- I will need to learn how to create a win and death screen for my game.
- I will learn how to randomly create bombs and spawn clue numbers correlating to the distance from the bomb.
- I will learn how to draw a surface filled with tiles in a grid.

## Outcomes
Ideal Outcome:
- The ideal outcome is that this code program creates and runs a game of minesweeper almost identical to the Google version.

Minimal Viable Outcome:
- The program creates a screen full of tiles in a grid.
- Random tiles are hidden bombs that will explode when the player interacts with them.
- Numbers spawn next to the bomb, the number on the tile will indicate how many tiles it is away from a bomb
- There is a win screen and a death screen.
- The player can interact with the game.

## Milestones

- Week 1
  1. Create the board.
  2. Create the tiles.
  3. Draw the tiles on the board.

- Week 2
  1. Create the mines that explode when a character interacts with them.
  2. Create the clue numbers that spawn near the bombs.
  3. Create the dig algorithm.

- Week N (Final)
  1. Create the win screen and the death screen.
  2. Innovate: find ways to make the game unique to me.
